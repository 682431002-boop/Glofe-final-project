# GloFe — Global Pre-Order

Fresh rebuild in plain HTML, CSS and JavaScript.

## Pages
- index.html — Home + product shop + login/sign up
- product.html?id=1 — Product Detail
- wishlist.html — Wishlist
- cart.html — Shopping Cart
- payment.html — Checkout / Payment
- account.html — My Account + Order History

## Product images
Replace the placeholder SVG files in `assets/images/` with your own JPG/PNG files, then update the `image` path in `app.js` if the filename changes.

## Demo features
- EN / TH language preference
- Shipping country selector
- Search and country filter
- Product Detail + quantity
- Wishlist
- Shopping Cart
- Login / Sign up
- Payment / Checkout
- Order History
- LocalStorage data persistence

## Important
Authentication and orders are browser-only demo data. Do not use this version for real customer passwords or payments. Connect a secure backend, database, and payment gateway before production.
